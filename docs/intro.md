# The Rhumb Programming Language

Keep your mind open and enjoy!

## Getting Started

Download the git repo. Compile and run `grhumb` for a basic repl.

### What you'll need

- [Go](https://go.dev) version 1.19 or above
- [antlr4](https://github.com/antlr/antlr4/runtime/Go/antlr/v4) v4.0.0-20221202181307
- [acmd](https://github.com/cristalhq/acmd) v0.11.0
